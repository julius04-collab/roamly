# Roamly — Day 4 / 30 Days of Landing Pages

Landing page for **Roamly**, a fictional curated-travel brand (Cape Town, Marrakech, Bali, Zanzibar). *Less planning. More living.*

**Highlights**
- Video hero with a "roam" text-cutout intro that opens into the film on scroll; live "Now showing" chapter sync
- Floating pill nav with sliding hover blob + scroll-spy; full-screen circular-wipe mobile menu
- Pinned horizontal destination gallery
- Scroll-driven journey map: route draws Marrakech → Cape Town → Zanzibar → Bali with camera zooms
- Collage zoom: centre photo expands to full screen as tiles scatter
- Working trip-style finder that recommends a destination and pre-fills the enquiry form
- Client-side validated enquiry form with error summary and success state (demo, nothing is sent)

**Stack:** single static `index.html`, GSAP 3 + ScrollTrigger (cdnjs), WebP images, H.264 hero film. No build step.

Prices, itineraries and traveler profiles are illustrative. Photography via Unsplash; hero film cut from those stills.
